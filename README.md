# 实验验证两种编码说关于表象的论证（网页程序）

键盘反应时、正式 80 + 填充 20、可导出 CSV/JSON；可选接 Supabase 收数据。

## 运行

```bash
cd size_judge_lab
python -m http.server 8080
```

浏览器打开 `http://127.0.0.1:8080/`（勿用 `file://`）。

Windows 可双击 `start_server.bat`。

## 图片（可选，稍后补）

见 `stimuli/README.txt`。无图时图画试次显示占位框，仍可调试流程；**正式收数据前请补全图片**。

## 逻辑摘要

- 被试编号自动生成。
- 练习：6 试次，图画一致/不一致；正式前正确率阈值见 `config.js`。
- 正式：20 词对 × 4 条件，块拉丁方 + 同对最小间隔 + 左右平衡。
- 每 4 个正式后插入 1 个**文字**填充（共 20），`includeInAnalysis=0`。
- 完成第 30、60 个**正式**试次后插入注意检查。
- 仅 `←` `→` 按键记录 RT（`performance.now()`）。
